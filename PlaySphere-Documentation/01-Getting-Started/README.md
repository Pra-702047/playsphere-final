# PlaySphere

![PlaySphere Banner](https://via.placeholder.com/1200x300?text=PlaySphere+Enterprise+Sports+Platform)

PlaySphere is a modern, enterprise-grade sports venue booking and management platform built with Next.js 15, Firebase, and Razorpay. It provides a seamless PWA experience for players to discover and book turfs, and a robust administrative dashboard for turf owners to manage inventory and revenue.

## Key Features
- ⚡ **Server-Side Rendering (SSR)** via Next.js App Router for optimal performance and SEO.
- 🔒 **Enterprise Security** via Firebase Authentication and strict Firestore rules.
- 💳 **Secure Transactions** powered by Razorpay with automated settlements.
- 📱 **Progressive Web App (PWA)** for native-like mobile experiences.
- 📊 **Real-time Analytics** for turf owners.
