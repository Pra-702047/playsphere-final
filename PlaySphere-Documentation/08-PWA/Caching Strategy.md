# Caching Strategy

PlaySphere employs a hybrid caching strategy generated by `next-pwa` and Workbox.

## Strategies Employed
1. **Cache First (Static Assets):** Images, fonts, and Next.js bundled JavaScript chunks are served directly from the cache to ensure maximum speed. The network is only queried if the asset is missing.
2. **Network First (Dynamic Data):** For API requests (if cached) or HTML document requests, the Service Worker attempts to fetch the latest version from the network. If the network fails, it falls back to the last cached version.
3. **Stale-While-Revalidate:** For less critical assets, the cache serves the asset instantly while simultaneously querying the network in the background to update the cache for the next visit.
