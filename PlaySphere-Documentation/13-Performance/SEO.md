# SEO (Search Engine Optimization)

## Next.js Metadata API
PlaySphere dynamically generates HTML `<head>` metadata via the Next.js `generateMetadata` API.

## Key Implementations
- **Dynamic Titles/Descriptions:** Turf detail pages dynamically inject the turf's name, location, and description into the title tags.
- **Open Graph (OG) Tags:** Facebook and Twitter card metadata is populated for rich link previews when users share a turf URL.
- **Semantic HTML:** Strict adherence to hierarchical heading structures (`<h1>`, `<h2>`) and accessible ARIA labels to boost crawler indexing.
