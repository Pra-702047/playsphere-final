# Admin Manual

## Super Admin Dashboard
The Admin Dashboard provides platform-wide oversight.

- **Verification:** New turfs added by owners must be manually reviewed and marked as `isActive = true` via the database or admin panel before they appear in public search results.
- **Disputes:** Admins have global read access to the `audit_logs` and `payments` collections to investigate disputed charges or double-booking claims.
- **Metrics:** View global GMV (Gross Merchandise Value) and total user acquisition metrics.
