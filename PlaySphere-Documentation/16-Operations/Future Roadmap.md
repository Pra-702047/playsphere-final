# Future Roadmap

1. **Razorpay Route (Split Payments):** Automate payouts directly to Turf Owners' bank accounts at the time of booking, taking only the platform commission.
2. **WhatsApp API Integration:** Send instant booking confirmations and OTPs directly to players' WhatsApp numbers via Twilio or Meta API.
3. **Dynamic Pricing Engine:** Allow owners to set higher prices for peak hours (e.g., 7 PM - 10 PM) or weekends automatically.
4. **Subscription Models:** Implement a SaaS payment tier allowing owners to unlock advanced analytics and SMS features for a monthly fee.
5. **Review System:** Launch the `reviews` collection to allow players to rate turfs out of 5 stars, influencing search ranking.
