# Release Notes

## v1.0.0 (Current Production Release)
- **Performance:** Migrated homepage and search to Next.js Server Components, eliminating client-side data waterfalls.
- **Features:** Launched PWA Install prompt for seamless mobile installation.
- **Security:** Hardened Firebase Security rules and shifted offline booking creation to a secure server API.
- **Payments:** Integrated Razorpay checkout with HMAC server-side signature verification.
- **Dashboard:** Deployed comprehensive Turf Owner dashboard with OTP check-in capability.
