# Glossary

- **Turf:** An artificial grass sports facility, typically used for football or box cricket.
- **Slot:** A specific 60-minute time block available for booking at a turf (e.g., 18:00 - 19:00).
- **Offline Booking:** A reservation made by a customer via phone call or walk-in, which the Turf Owner manually inputs into the dashboard to block the slot.
- **Check-In:** The process of verifying a player's arrival at the venue using a 4-digit OTP generated by the platform.
- **Admin SDK:** A privileged backend library used to bypass client security rules for secure operations.
